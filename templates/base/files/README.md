# My app

Effect 4 + TanStack Start on Cloudflare Workers, generated by [efforge](https://github.com/amagdy46/efforge).

## Develop

```sh
pnpm install
pnpm dev        # http://localhost:3000 (or the port Vite prints)
```

## Scripts

| Command          | What it does                      |
| ---------------- | --------------------------------- |
| `pnpm dev`       | Start the dev server              |
| `pnpm build`     | Build every workspace             |
| `pnpm typecheck` | Type-check every workspace        |
| `pnpm lint`      | Biome check                       |
| `pnpm test`      | Run tests (`@effect/vitest`)      |

## Layout

- `apps/web`: TanStack Start app (routes in `src/routes`, Effect layers in `src/server/layers.ts`)
- `packages/core`: service interfaces shared across the app
- `efforge.jsonc`: the choices this project was generated with; `efforge add` reads it
